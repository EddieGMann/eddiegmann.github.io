All projects are specifically made to work with items (surveys, photos and canvas screen shots) created for the program. None of the python programs connect back to any LLM or internet soucre. You will need your own offline files to work with. This is done to ensure privacy is maintained.

  • Evaluation Summary Generator
    • You can download the results .csv and then use that file to create the charts preferred by departmental leadership to summarize the results. You will still need to create a header for the page that describes the class, instructor, and program within the department.
  • Photogrid Generator for MB
    • Download photos, label them with LastName, FirstName, and then create a .zip with all photos. Load .zip into the generator and then you have a grid of that year's students. Useful since you will be asked to make the same grid 8 times because students come late or drop out.
  • Simple Gif Maker
    • Used to make .gifs from screenshots. Remember to change the caption when adding steps.
